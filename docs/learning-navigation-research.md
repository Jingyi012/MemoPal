# 学习导航与个人资料库调研

调研日期：2026-11-09。范围：Quizlet、Knowt、Anki 的官方说明，以及当前 MemoPal 移动端相关页面。本文件是产品建议，没有修改实现；竞品资料说明其公开的功能与流程，不能证明某种布局最适合 MemoPal 的儿童用户。

## 建议先说

在“以孩子日常学习为主，记忆方法可选”的定位下，建议让「学习」默认回答“我现在学什么”，以继续学习、当前任务和自己的资料为主；让公开课程通过明确的「发现课程」入口承担找新内容的任务。不要让孩子每次回到学习区，都重新面对整个公开目录。

这不等于把个人资料库直接当成学习首页。两者解决的问题不同：学习首页承接行动；「我的资料」承接查找与整理；「发现课程」承接探索。以上是待验证的产品假设，不是竞品证明的最优解。

## MemoPal 当前实现观察

- `apps/mobile/src/features/education/screens/EducationPublicCoursesScreen.tsx` 同时承担学习入口与公开课程目录，已有继续学习卡、首次推荐与「我的任务」。因此现状不只是“纯目录”，改进重点是主次和多种内容来源的承接。
- 该页头部的资料库图标进入 `/education/my-courses`，个人资料的持续可见性较弱；`EducationPersonalCoursesScreen.tsx` 已合并自建和收藏内容，提供「全部／我创建的／已收藏／草稿」筛选。这一合并值得保留。
- 上述学习入口对 RestrictedLearner 已重定向到任务页。不同账号模式要分别评估，不能笼统声称所有孩子当前都默认看到公开目录。

## 建议的最小信息架构

学习区保留一个主入口，在内部明确呈现三个去处：

1. **今天学习（默认）**：优先显示当前任务或继续学习，根据真实状态展示待复习；推荐一个清楚的主行动，再保留查看全部任务和换一份资料的入口。未有资料时展示一个适龄体验推荐，并提供「发现课程」「创建资料」。
2. **我的资料**：自建与收藏统一列表，以最近使用排序；「我创建的／已收藏」是来源筛选，「进行中／已完成」是学习状态，避免把两者混为互斥分类。资料多后再评估学科或文件夹，暂不新增复杂整理系统。
3. **发现课程**：公开目录、搜索、学段及学科筛选。课程可直接试学，也可收藏回自己的资料库；收藏不等于已开始，浏览不等于加入学习计划。

三个去处可用学习区内的清晰文本导航实现；不必为每个去处再增加底部主标签。若现有全局首页已完整承担“今天学习”，则学习默认可直接进「我的资料」，避免再造第二个活动首页。需要先核对整个 App 的首页职责，再确定最终落点。

公开课程开始学习后，应在「继续学习」中可找回，即便没有点击收藏；是否自动纳入个人资料需要明确规则并验证，不能无提示地把“收藏”变成学习历史。自建、收藏公开课和老师任务都应能在活动层被找到，但各自的所有权、编辑权限及任务进度不因此合并。

## 记忆方法的地位

宫殿、数字桩等保留为可选工具。孩子可从学科内容的相关学习步骤进入方法辅助，不需要先理解“宫殿/数字桩/记忆库”的分类才能开始学。工具区仍可独立管理已有资产，重度用户保留快捷进入方式。

不要因为降低导航权重就迁移或合并底层记忆资产。若实际验证表明「记忆库」容易被理解为另一个资料库，可测试「记忆工具」名称；这是命名实验，不是直接重命名实现的要求。

## 验证方式与决策条件

先做两版低保真：A 保留当前目录优先、加强个人资料入口；B 活动优先、显式提供我的资料与发现。招募覆盖小学与中学的孩子，分别测试首次使用和已有学习记录；家长辅助与独立使用分开观察。

让参与者完成：继续昨天内容、找到自己创建内容、找到收藏课、发现指定学科新课、找到老师任务、按需使用记忆方法。记录首次点击、完成情况、是否误入公开目录、需要提示的次数，以及“收藏／进行中／任务”的理解。用中性任务措辞，避免在任务里提前告诉孩子导航名称。

若大部分回访任务是继续或找自己的资料，且 B 能降低查找成本，可采用活动优先。若新课程探索是实际高频任务且 A 更顺畅，保留发现权重。正式上线后再观察返回用户开始有效学习所需时间、继续学习成功率，以及发现与收藏后的实际开学率；不以目录点击率单独判断成功。

## 限制

本次只使用官方网页与本地源码，没有登录竞品逐屏检查，也没有 MemoPal 用户行为数据或儿童可用性测试。Anki 的桌面操作说明不是移动导航证据；Quizlet 的大学生优化首页不是儿童适配证据。建议基于产品定位及任务拆分，仍需通过上述测试确定。

## 本轮核对后的推荐落点

2026-11-09 核对底部导航后，当前共有首页、学习、社区、记忆库、进度、我六个入口。
建议产品方向采用四个主入口，作为待验证方案：

| 主入口 | 回答的问题 | 建议内容 |
| --- | --- | --- |
| 学习（默认打开） | 我现在继续做什么？ | 一个主要下一步行动；继续学习、真实到期复习、老师／家长任务、最近资料 |
| 资料库 | 我的东西在哪里？ | 合并个人课程资料与原记忆库的入口；内部区分课程和记忆练习，统一搜索和列表／双列外观 |
| 发现 | 我还可以学什么？ | 官方预设课程、公开课程及合适的社区内容；浏览课程可试学，不强迫先收藏 |
| 我 | 我的账户与成长情况？ | 学习报告／进度、设置、家长相关入口等；常用报告仍可从学习页摘要进入 |

现有全局首页与学习首页的日常行动能力合并到新的默认学习页，避免出现两个争夺
“今天做什么”职责的页面。资料库虽独立，但首页露出最近使用资料及直接继续动作，
不用先到资料库再开始。课堂受限账号继续遵守其任务优先和可见性限制，不能因为
合并导航就暴露标准账号的公开发现、创建或社区能力。

资料库首期提供「课程／记忆练习」两种内容视图，记住上次所选；课程中的
「我创建的／已收藏／草稿」仍是课程筛选。不要把课程、来源、完成状态和记忆方法
堆在同一排互斥 chips。原有记忆文件夹、归档、宫殿照片和数字桩管理保留原来的
语义与权限；跨内容类型文件夹不是本轮导航合并的必需条件。

这属于入口与展示层整合，并不意味着把课程与记忆集强制变成同一个数据实体。
同一课程已关联的记忆练习在课程内提供可选「帮我记住」入口；打开关联练习不复制
一份学习内容，也不把记忆练习分数当成课程测评成绩。独立创建的记忆练习仍能单独使用。

目标操作路径（不包括解锁设备、登录和首次权限确认）：

- 回访：默认学习页 → 继续学习 → 上次有效步骤，目标一次点击。阅读位置与作答成绩分别保存。
- 换资料：资料库标签 → 资料卡的继续／开始动作，目标两次点击；点标题可看课程详情。
- 找新内容：发现 → 课程预览／试学；收藏后可在资料库找到，开始过的内容即使未收藏也能从最近学习找回。
- 家长上传：添加学习内容 → 扫描与核对 → 保存并开始；内容进入资料库，孩子的受限账号通过既有授权或任务机制接收，而非自动读取家长全部私人资料。

收藏、开始学习、草稿三者保持独立：收藏是保存入口，开始才产生学习活动，草稿
尚未准备好供孩子学习。首页的下一步要从真实活动／到期／任务状态决定，不能直接
用修改时间或收藏时间猜测。新用户没有活动时，呈现一门适龄体验课与创建／扫描入口；
有自己的资料后，公开推荐降低到页面后段或发现区。已知记录加载失败时显示重试，
不能把错误当成新用户无资料。

实现顺序建议先改学习页的个人内容优先和直接继续路径，再整合底部资料库入口，
最后合并现有全局首页和学习职责以及发现／报告入口。先保留旧深链接跳转，避免
一次性迁移课程、记忆集、文件夹、所有练习状态。

本地核对发现私人课程摘要当前仅有 id、名称、语言、可学习标记和卡片数量，没有
跨资料源统一的最近学习时间和精确阅读位置。若承诺跨设备续学及混合最近排序，
需要补充真实活动来源／恢复定位，不能只调整卡片排序。现有 `start=1` 私人课程入口
可复用，但恢复到具体卡片仍需核实所保存状态。所有权、任务成绩和复习时间继续服务端权威。

补充一手依据：[RemNote Flashcard Home](https://help.remnote.com/en/articles/7925835-the-flashcard-home)
在同一入口安排今日复习与按文档练习，支持“任务行动与资料列表共存”的判断；
[Duolingo 2022 首页设计说明](https://blog.duolingo.com/new-duolingo-home-screen-design/)
说明引导下一步和将练习纳入路径的设计动机，这是历史设计依据；
[当前 Practice 功能说明](https://blog.duolingo.com/guide-to-duolingo-practice-hub/)
说明针对技能的练习可另有入口，不能据此认为全部辅助功能都应塞进学习主流程。

选择这一方案的依据是 MemoPal 已明确的“学习为主，记忆方法辅助”定位；它不是
已通过儿童研究证明的最优设计。验证优先记录回访用户开始有效学习的耗时、找到
自建／收藏材料的成功率、需要返回或求助的次数，并按年龄及账号模式分别评估。
