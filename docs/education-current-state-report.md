## 1. 执行摘要

MemoPal 已经有一套跨移动端、管理门户和 API 的教育功能。当前不是只有界面原型：课程与测评创作、多个题型、家庭/课堂关系、任务分配、学生作答、服务端评分、人工批改、结果发布、部分报告和排名、公有课程自主练习都已经实现了相当一部分。

模块仍标记为“实施中”，不应宣称教育产品已完整交付。主要原因包括：教育入口和体验分布在 Community、Home、Education Portal 多处；桌面端学生答题流程尚未提供；儿童/监护产品规则仍待明确；照片/语音与计时提交等需真实设备验证；内容课程、创作者与学习者体验还有待产品化；公开网页预览与若干内容迁移/同步功能没有完成。

当前教育由两类互相隔离的学习流程组成：

1. **公开自主学习**：登录用户从 Community 发现公开课程，浏览、收藏、做允许公开练习的题目、查看自己的最小化练习历史。它不产生正式作业成绩、掌握证据或教师/家长报告。
2. **授权教学流程**：作者创作课程；教师管理班级并布置课堂任务；已验证监护人给关联孩子布置家庭任务；学习者提交；教师/监护人批改和发布结果；授权用户查看报告。

教育与原有记忆、复习、Library 模块采取“复用组件和可选链接，保留业务边界”的集成方式。MemorySet/PracticeAttempt 的含义不变；教育课程、AssessmentAttempt、Assignment、Grade/Publication 等有各自的领域与权限规则。

## 2. 产品范围与核心边界

### 2.1 当前涵盖的产品能力

- 公开课程发现、课程详情、收藏、公开自主练习和个人练习历史。
- 教育课程、学习目标/知识点、测评、版本化题目与答案配置。
- 家庭监护关系、课堂及成员关系、邀请、确认、管理员核验和撤销。
- 家庭/课堂任务分配、学生作答、自动保存、提交、截止处理和服务端评分。
- 教师/监护人查看成绩册、人工批改、成绩更正、发布成绩及针对性补测。
- 家庭报告、课堂目标证据、任务范围排名快照和后台公开课程审核。
- 知识点对 Community 中当前可发现的公开 MemorySet 的可选推荐。

### 2.2 不应混为一谈的概念

| 概念 | 目前语义 |
|---|---|
| `MemorySet` / 记忆素材 | 现有记忆工具与 Community/Library 内容实体；不代表课程或正式试卷 |
| `PracticeAttempt` | 现有个人记忆练习/自评记录；不自动变成教育正式成绩 |
| Community 公开自主练习 | 用户对作者公开并明确允许自主练习的题目即时作答；只保存用户自己的最近练习摘要 |
| Education assignment / attempt | 分配给特定家庭成员或课堂成员的正式任务、提交和评分流程 |
| 正式成绩/排名/掌握证据 | 由后端、授权关系、版本与发布状态控制；与社区 XP/参与分开 |
| Library 收藏 | 用户保存的个人记忆资料；教育课程收藏是单独的用户课程收藏记录 |

重要隐私/评分边界：学生答题 DTO 不下发答案键；答案由后端评分。公开练习的答题反馈只在用户作答后返回；公开练习不创建正式 Attempt、成绩、掌握证据、班级排名或家长/教师报告。正式成绩在所有必要人工评分完成并由任务所有者发布之前不向学生披露。照片/语音附件在私有存储中，并在每次读取时重新检查访问权限。

## 3. 用户角色和权限模型

角色按能力叠加，而不是互斥账号类型：同一个用户可以是普通学习者、课程作者、教师、学生/任务接收人和监护人。

- **普通学习者**：不要求班级关系或学生账号即可浏览公开课程、收藏和自主练习。
- **课程作者**：创建本人课程/知识点/测评；选择课程是否公开，以及发布的测评是否可用于公开自主练习。公开课程本身不授予作者查看学习者身份、正式成绩或班级数据的权限。
- **教师/课堂教育者**：由拥有的课堂或有效课堂关系授权，可管理相应班级、邀请成员、布置任务和查看受限成绩/报告。
- **任务接收者/学生**：只查看本人被分配任务、提交和授权发布的反馈/成绩。
- **监护人**：需学生确认和管理员核验的有效关系，权限按当前关联孩子限制；关系撤销后报告接口访问应随之停止。
- **平台管理员**：后台可处理待核验的监护关系、公开课程举报与审核等管理职责。Admin 权限不能被当作普通教师跨班级查看学生数据的替代授权。

## 4. 用户入口与导航现状

### 4.1 手机端入口

应用底部主导航为 Home、Practice、Community、Library、Progress、Me；教育目前没有独立底部 Tab。

- **公开课程**：Community Tab → Discover 页面中的学习快捷入口 → `/community/education`。
- **课程作者**：Community Discover 页面里的 creator/authoring 链接，在管理门户地址配置可用时打开 Education Portal。
- **学生任务**：Home 中有任务时显示 Education assignments 区块；点击任务进入 `/education/assignments`。也可从 Portal 学生卡片打开 MemoPal 的任务深链。
- **课堂邀请、监护请求**：Home 和任务页可显示待处理状态，确认/拒绝后刷新相应数据。
- **家庭报告**：有关联孩子时显示家庭报告快捷入口，进入 `/education/family-reports`。
- **自主练习/复练**：任务页提供已提交且成绩发布任务的复练入口，路由 `/education/practice`；Community 学习页则进入公开课程练习。
- **公开课程收藏/历史**：课程目录页提供快捷入口，分别为 `/community/education/saved` 与 `/community/education/history`。

Home 有意在没有作业时隐藏空的任务区，但保留加载和错误状态以便恢复；所以没有收到作业的普通用户不会看到一张空课堂卡片。

### 4.2 管理端 Education Portal

管理端 Vite/React 应用的教育工作区路由：

- `/education`：学习工作区主页、当前账号能力、班级和待接受邀请。
- `/education/courses`、`/education/courses/:courseId`：课程与目标管理。
- `/education/assessments/:assessmentId`：测评和题目编辑/发布。
- `/education/classrooms/:classroomId`：班级详情、成员、作业、成绩册和进度。
- `/education/family-practice`：监护人家庭练习管理。
- `/education/guardians`：监护关系工作区。
- `/admin/education/course-reports`：平台管理员的公开课程举报审核队列。

登录后的普通账号默认导向 `/education`，管理员默认导向平台管理页；安全且允许的教育深链可保留。教育主页中的角色卡依据有效关系动态显示。课程作者入口向所有用户开放，不要求教师身份。

### 4.3 路由清单（移动端）

- `/community/education`
- `/community/education/:courseId`
- `/community/education/:courseId/:assessmentId`
- `/community/education/saved`
- `/community/education/history`
- `/education/assignments`
- `/education/practice`
- `/education/family-reports`

应用深链用于 App 内路由与登录后安全返回。公开 HTTPS 课程预览和未安装 App 的落地/安装回退尚未实现，文档记录原因是尚无已验证的公开移动 Web origin/hosting route。

## 5. 主要用户流程与资料查看

### 5.1 普通用户自学

1. 登录 MemoPal，进入 Community 的公开课程入口。
2. 在公开课程目录搜索、查看作者和课程题目数量，打开课程详情。
3. 查看目标/说明、作者推荐的公开 MemorySet（如有）。
4. 只有明确发布为公开自主练习的测评能被公开答题；点入后用共享题型输入组件作答，服务器返回答题反馈/解析。
5. 可收藏课程；之后从收藏页重新打开仍公开的课程。
6. 可在个人历史查看仍公开的课程/题目最近练习记录。该记录不保存原始答案，只保存资源引用、时间与最近正误；课程撤下后不会继续从公开历史展示。

### 5.2 学生完成正式作业

1. 收到并接受课堂邀请（如需要），在 Home 或 Education assignments 查看已分配任务。
2. 查看开放时间、截止时间、是否限时等任务信息；在允许时间内开始或恢复作答。
3. 题目答案通过版本化队列保存，正式作答/私有附件有单独后端合同。超时按服务端规则处理；客户端不得自报分数。
4. 提交后查看状态；成绩和反馈只在所需人工批改完成且任务所有者发布结果后可见。
5. 发布后可看本人结果/排名；是否参与班级完整化名榜与任务是否启用、个人是否同意有关。教师更正会撤销现有结果发布，需重新发布后新结果才可见。
6. 已提交且成绩已发布的任务可进入独立复练路径，不改正式提交、分数、证据或排行榜。

### 5.3 教师/课程作者

1. 登录 Education Portal，进入 Courses 创建课程与目标。
2. 建立 Assessment，配置题型、题目、选项、标准答案/评分规则、可选解释与开放题 Rubric；可预览学生可见表单，预览须排除答案键、答案 ID、Rubric 和目标 ID。
3. 发布测评版本。课程公开与该测评是否允许公开自主练习是分开的选择；课堂正式任务默认私有。
4. 在班级分配版本化快照，或在家庭工作区为已验证孩子布置家庭任务。
5. 从成绩册查看状态、批改开放题、发布结果；必要时记录原因并建立独立补测任务，或进行带审计的最终成绩更正。
6. 从授权课堂报告查看目标证据。知识点掌握基于已发布结果、不可变版本、样本门槛、证据窗口等规则；仅选择题证据不会被误标为已掌握。

### 5.4 家庭关系与报告

学生端可以发起/确认监护关系流程并查看对方显示名、授权范围；管理员处理核验。有效监护关系可访问所授权孩子的家庭任务和已发布结果。家长不可修改教师成绩；撤销关系后服务端应立即拒绝相应报告访问。

## 6. 教育题型与学习能力

已记录为端到端实现的题型：

- 单选、判断、填空/数值。
- 多选、排序、配对（排序提供可访问的上下移动操作，不依赖拖动；配对支持部分匹配和按规则部分得分）。
- 文字简答、照片作答、语音录音作答（后端 Rubric 人工评分闭环）。

正式测评题目答案由服务器负责校验和评分。照片允许经过验证的 JPEG/PNG/WebP，语音按允许音频格式校验并存私有目录。当前没有自动语音转写或发音评分。语音是人工批改试点，录音时会限制导航/提交冲突；设备层录音、回放、恢复仍需实机确认。

公开自主练习的支持范围另受发布政策约束：公开答案的题目不能被视为保密试卷；公开测评只适合练习，不适合作为要求题目保密的考试。

## 7. 与现有 MemoPal 主模块的集成关系

### 7.1 已存在的复用/连接

- 公开自主练习和作业复练使用 Education 的共享 question input 组件；正式作业也复用答题输入，但通过不同的业务 API、状态与结果政策运行。
- 教育发现入口放在 Community，不新增独立底部导航 Tab。
- 目标可选推荐 Community 当前可发现的公开 MemorySet；推荐是 ID 引用。用户跳转到现有 Community 详情/复制/Library 流程。
- 教育题目在学生、老师、报告等界面间用类型化 DTO/API；服务端维持作答、权限、评分和发布权威。
- 登录返回路径允许安全的公开教育路由（课程/练习/收藏/历史）以及部分社区路由。

### 7.2 明确保留的隔离

- 不把 `MemorySet` 转换成教育课程，也不把历史 `PracticeAttempt` 转成正式成绩。
- 自主公开练习记录不进入正式 Education Attempt、课堂掌握分析、家庭报告、分数榜。
- 正式测评在开始/作答时不向学生下发答案键；公开练习不承诺答案保密。
- 私人宫殿位置、关联联想和私人照片不复制到课程、测评版本或公开分享。
- 社区参与分/XP、正式成绩、掌握证据和作业排名分别计算；考试得分不兑换社区学习分。
- 家庭/课堂授权不由“公开课程”或“作者身份”自动产生；每次后端读取按有效关系和资源范围验证。

### 7.3 尚未做的连接

- 课程内容复制到个人 Library。
- 知识点推荐私有/未列出记忆素材（当前首期选择范围是可发现公开集）。
- 课程与个人记忆练习之间的自动快捷方式/复习联动。
- 跨设备同步自主练习题型筛选偏好。
- 安装外公开课程 Web 预览与稳定的 App 安装回退落地页。

## 9. 已实现程度与阶段理解

### 已经形成的闭环

- 课程创作 → 发布 → Community 公开浏览/自主练习（如果测评单独开放）。
- 教师课程/题目创作 → 班级任务 → 学生保存/提交 → 教师评分/发布 → 学生查看结果。
- 监护关系建立/确认/管理员核验 → 家庭任务 → 家长成绩册与报告。
- 开放题提交 → 私有照片/音频附件 → 人工批改 → 批改完成后发布。
- 目标证据、按任务排名快照、成绩更正后撤销旧发布并重新发布。
- 社区课程举报 → 管理员审核/隐藏/恢复。

### 相对原规划的阶段覆盖

规划文档的原路线是 E1 家庭练习、E2 课堂作业、E3 测验/掌握/班级榜、E4 更丰富教学。实现状态显示项目已经覆盖了 E1-E3 的不少实质能力，并实现了部分原 E4 语音输入/照片与人工评分基础；但不能由此推导为阶段整体完成：产品决策、端到端体验、设备验证、真实部署验证和验收仍有缺口。用“功能已实现”描述单项，用“阶段完成”必须有阶段验收证据。

## 10. 未完成、待决策和风险清单

以下状态来自实现状态文档和代码边界，后续 AI 应再次核对是否有新提交更新：

1. **端到端产品体验尚未完整**：教育能力入口分散在 Community、Home、Education Portal；移动端没有一个总览式学习首页/教育 Tab。要不要统一入口属于产品取舍，不能默认一定要加 Tab。
2. **桌面学生作答**：Education Portal 明确把学生任务深链到移动 App；没有等价的完整 Web 学生答题器。
3. **儿童/家庭策略**：目标年龄、关系核验方法、上线地区和相应产品流程仍待决定。
4. **设备验收**：iOS/Android 实机检查计时交卷、弱网恢复、录音/回放、照片、附件读取和缓存清理。
