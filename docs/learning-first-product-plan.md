# MemoPal：学习优先的产品实施计划

日期：2026-10-29。状态：实施中；本文件是验收清单，不代表功能已经交付。

## 产品定位与范围

把官方课程、家长上传的学校资料和教师任务，变成儿童愿意完成的小课。学习是主线，记忆宫殿、数字挂钩和图片联想是可选辅助。小学识字、词汇、听写是首批验证场景；保留中学生和成人可使用的表达与内容能力，不把全产品锁定为低龄游戏。

本计划记录本次对话的完整范围，不能用仅更改首页或增加种子题代替完成。此前 HTML `MemoPal 学习模块 UI 定调.html` 仍是视觉基准：紫粉渐变、学科色彩、大圆角、底部厚阴影、Nunito 字体、伙伴、短促反馈。遵循手机明暗主题、减少动画、文字缩放和至少 44pt 点击区域。

## 学习结构和主流程

- 学科 → 课程 → 单元 → 小课 → 知识点／学习条目；题目关联条目与知识点。
- 官方内容、个人上传内容、教师任务共用学习与练习机制，保留权限、内容来源和成绩边界。
- 小课：学一点 → 练几题 → 小挑战 → 完成 → 后续复习。
- 语言课按目标组合听说读写，不要求每课四种齐全；数学和科学采用操作、观察、分类、比较、推理等活动。
- 识别、描红、拼写、无提示回忆是不同学习证据；XP、练习参与和正式成绩不得混用。
- 学习卡片提供次要“帮我记住”入口；反复出错或完成后推荐一次。允许跳过，不影响完成和奖励，不反复弹窗。
- 宫殿地图导航不冒充记忆训练；真正训练包括建立联想、隐藏提示和回忆。宫殿加挂钩组合属于进阶选项。

## 官方内容与首次体验

- 新用户不上传也能开始；首页只有一个突出主动作，已有学习时继续，没有时推荐可用官方体验课。
- 初始偏好：阶段、科目、内容语言，可跳过和修改。无匹配内容时诚实展示体验课，不宣称覆盖教材。
- 官方课程标识由服务器控制；发布与首页推荐分开。推荐初期用人工配置和确定性规则。
- 首批目标：中文“我的校园／我的生活”、英语“School things／Everyday actions”、数学“分数／图形规律”，共六个体验单元。每单元三节小课、一次挑战和后续复习；用真实试用调整课长。
- 每单元须有适用阶段、学习目标、教学内容、媒体、提示递减练习、挑战、解释和复习映射；适合时附预制记忆辅助。
- 原科学／数学／英语种子内容作为已有体验素材，未经内容审核不得称正式年级教材；既有发布记录不可覆盖。

## 自定义学习和 AI

家长拍照／粘贴 → OCR 确认 → 语言／阶段／目标 → 生成小课草稿 → 预览确认 → 分配孩子 → 孩子学习 → 查看具体薄弱项。

- 听写目标最终包含无选项回忆，不以选择题代替听写掌握。
- 优先已审核词库和确定性模板，再以 AI 补充例句、合理干扰项和联想故事。词库不足时可以改题型，不强凑选项。
- AI 不改原始学习要求；内容生成在备课时完成，保存稳定版本。多音字、多答案、重复选项、错误解释需检查。
- 语音转写不是发音评分，手写识别不是笔顺评分；不展示没有可靠证据的能力成绩。
- 家庭私有材料、孩子录音及个人记忆联想保持私有；现有监护和课堂授权仍由服务端执行。

## 交互与视觉验收

- 首屏明确今天做什么；一节小课有具体、短小目标。
- 普通答对短反馈、克服难题强化鼓励、完成小课完整庆祝；不通过答错停学或惩罚连续天数制造压力。
- 官方课程、任务、扫描入口有清晰层次；记忆工具为次要入口，不能抢走学习主动作。
- 题型使用适合的交互；反馈不遮挡内容和下一步；长文本、窄屏、键盘、明暗主题均检查。
- 内容渐进呈现，预设宫殿／联想可直接体验，不要求孩子先配置工具。
- 中英文可读、可缩放；无障碍标签及减少动态效果可用。
