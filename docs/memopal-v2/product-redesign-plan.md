# MemoPal 2.0：互动学习与记忆伙伴

日期：2026-10-26。状态：产品方向与分阶段实施计划；不是已完成能力清单。

## 1. 产品决策

面向普通自主学习用户，也服务学生、家长和老师，把知识变成有引导、有丰富操作、有反馈、有复习的短学习任务。普通用户首次进入就有平台准备好的入门课程可学，不以入班、等待老师布置或先创建记忆集为前提。儿童体验以小学阶段为首批设计对象，低年级与高年级使用不同的文字密度、提示和庆祝强度。

产品承诺：**跟着 MemoPal 学会一个知识点，用不同方式练习，再在合适的时候巩固它。**

参考 Duolingo 的课程组织、多种活动组合、及时反馈和逐步撤除提示；使用 MemoPal 自己的角色、视觉、声音和内容，不复制品牌资产。听说读写是语言学习的一组能力；数学、科学、常识也应有符合学科目标的交互。

普通用户选择课程并直接学习；孩子可以选择课程或老师任务，系统安排活动；家长和老师选择合适内容、布置任务、查看学习证据。记忆宫殿、Number Peg、故事联想为适合的知识提供可选辅助，不作为学习主线、入门前置要求或课程完成条件。课程自主学习与课堂学习共用真实内容/进度基础，授权入口各自明确。

官方产品研究与来源见 [研究记录](learning-experience-research.md)。研究描述与本计划提案应明确区分，竞品设计不自动证明适合我们的年龄段。

## 2. 与原建议的关系

保留老板材料中的内容优先、短课、自动复习、儿童/成人分区和可选 Memory Academy。修订以下内容：

- 不把语言词语当作唯一学习对象，也不固定每课都走听说读写四步。
- 不在第一版同时承诺完整国家课程库、AI 自动出题、语音精评和手写批改。
- 不把截图时代的 React Web / 未来 React Native 建议当成技术事实：当前主客户端是 Expo / React Native。
- 不照搬三或四个 tab 数量；先改善现有真实路径，再迁移导航，保留已授权功能和既有记录。
- 区分正式测评与自主练习。正式作业必须遵守提交、人工评分、发布结果机制；不能为了即时欢呼提前泄露答案。

## 3. 核心学习循环

选择课程或老师任务 → 知识点介绍/示范 → 有提示练习 → 混合题型 → 撤掉提示尝试 → 解释与重练 → 本课总结 → 后续复习。

每个活动只承担明确学习目标。短课长度先作为可测试假设，由试点儿童的完成情况调整，不宣称某个固定时长适合所有儿童。

示例课程：

| 课程 | 活动组合 | 学习证据 |
| --- | --- | --- |
| 华文：描述天气 | 听音选图、字词配对、组句、跟读、描写、短句表达 | 认读、理解、表达、书写分别记录 |
| 英文/BM：购物情境 | 对话选择、听力填空、词块排序、录音回答、短阅读 | 不能用选择题正确推断口语已掌握 |
| 数学：分数 | 图形选量、大小比较、等值配对、排序、数值填空、解释理由 | 计算与概念理解分开 |
| 科学：植物生长 | 图片观察、阶段排序、条件分类、判断并解释、回忆 | 顺序记忆与因果理解分开 |

以上是待制作的教学内容方案，不代表仓库已有完整课程或已获教材授权。

## 4. 活动矩阵

| 活动 | 适用目的 | 当前基础与下一步 |
| --- | --- | --- |
| 单选/多选/判断 | 辨认、判断、概念区分 | 已有端到端合同、作者与服务端评分；改善说明和反馈 |
| 配对 | 词义、公式等值、概念对应 | 已有独立左右列表与部分分；保留非拖拽操作 |
| 排序/词块组句 | 句子结构、过程顺序、大小排序 | 已有排序合同；增强儿童操作体验，允许重复文字但 ID 唯一 |
| 文字/数字填空 | 提取答案、拼写、计算 | 已有服务端评分；合理答案变体应由内容与服务端规则定义 |
| 阅读理解/情境对话 | 理解与运用 | 可先用现有题型承载文本；复用材料分组与分支对话另作合同 |
| 听音选图/听写 | 听辨、听力理解 | 需要审核音频、媒体合同、重播与无声替代；现有纯文本选项不足以宣称实现 |
| 图片热点/分类/数轴操作 | 空间、分类、数学表征 | 需要新媒体和坐标/分类答案合同、作者预览与服务端评分 |
| 跟读/口头表达 | 发音、表达能力 | 已有私有录音作业与人工评分；自动发音评分尚未实现 |
| 描红/临写/听写 | 笔画练习与独立书写 | 需要已审核笔顺数据、画布与轨迹合同；描红完成不等同独立会写 |
| 简答/照片作品 | 推理、创作、开放表达 | 已有人工评分作业；不伪造即时正确反馈 |
| 记忆场景挑战 | 顺序和知识提取 | 复用 Palace/Peg 与现有 objective-memory bridge；不重复创建成绩 |

题型丰富性来自教学目标和不同操作，不能仅把单选换背景称为新题型。每课有适当变化，但不强迫每课包含所有形式。

## 5. 反馈与儿童体验

每次操作有状态回应；只有服务端确认答案后才能反馈答对。普通答对使用短音效/轻动作，首次独立成功和纠错成功有明确文字，课末可以使用更强的拍手欢呼与伙伴庆祝。长庆祝必须可跳过，不阻断下一题。

错误反馈指出下一步：再听一次、看一个线索、重新排列，而不是惩罚或羞辱。不设置错误扣除学习机会的生命值。服务错误、麦克风未授权、识别失败与答错分开呈现。

优先复用当前音效、用户偏好、主题和角色。尊重静音、减少动态效果、屏幕阅读器和文字缩放；所有交互至少 44 点；拖动必须提供点击或上下移动替代。不只有颜色表达正确与否。正式题目的未发布结果仍隐藏。

奖励描述行为，不伪造学习成果。本轮完成、首次答对、重试后答对、仍需复习分别统计。“首次答对”只表示本轮第一次校验成功，不声称从未见过题目或独立掌握。XP、星星、连续天数不代表掌握度。开放题提交只庆祝表达/完成，未经评分不能称答对。

## 6. 导航与成人工作区

目标导航：今天（继续、任务、复习）、学习（课程与个人内容）、我的世界（伙伴、成果、成长）；Memory Academy 先作为学习内可选入口，后续根据使用情况决定独立目的地。

2026-10-27 用户补充优先级：普通用户一进入软件就应有课程可以学。因此先完成一级“学习”入口、首页首屏课程推荐/继续与平台默认入门课，再继续题目音频。仅将老师课程藏在 Community，或要求先创建记忆集，不满足当前定位。

现有 Community、公开课程、成人创作与受限学员策略必须先完成入口映射再调整。不能通过 UI 重排绕过 RestrictedLearner 的服务端限制。公开练习不是受限学员的默认课程通道。

成人区继续使用现有 Education authoring/assignments/gradebook。新增题型必须同时支持作者创建、验证、预览、发布及学习者作答；没有可维护的内容来源就不算完整交付。

课程→单元→小课→活动；使用学习目标组织内容。定义服务端课程进度与小课 session、版本、幂等提交和恢复合同，区分学习、复习与正式考试。先做经过审核的语言、数学、科学各一组小课，以检验引擎的跨学科能力。课程有范围和来源，不冒称官方完整课程。

### C. 听说读写与媒体活动

先审核媒体播放、听力选择/填空和录音回放，再做手写画布与笔顺；自动语音/手写评分在独立数据与儿童试点验证后启用。增加图片选项、材料块、分类/热点/数轴时同时扩展作者与服务端验证。

验收：设备权限、上传失败、恢复、音频中断、静音替代、媒体私有访问完整；每种新题型有输入、作者验证、答案合同、评分或人工待评状态和测试。识别不确定时不给虚假高分。

### D. 自适应复习与 Memory Academy

基于目标/技能的学习证据安排复习，区分识别与独立产出；记忆技巧作为可选辅助。复用已有记忆桥接并确定教育练习与个人记忆练习如何关联，不能直接把一次练习映射成正式成绩。

验收：日程和证据在服务端；相同知识跨场景不重复发奖；家长能分辨练过、会选、能表达和待复习。

### E. 导航迁移、儿童试点与发布

逐步调整入口、成人区与 My World；保留现有真实记录。用不同年龄、不同设备试点验证是否能独立开始、完成与再次练习。发布需内容审查、性能、无障碍、数据迁移（如有）和真实 iOS/Android 验证。

### 本阶段交付目标

把现有一次性的客观题练习扩展为可以退出、继续、跨设备恢复的真实学习小课。复用课程、学习目标和已发布且明确 opt-in 自主练习的 assessment 题库；不重复维护一套题目答案。现有正式 assessment attempt 保持独立。未来增加明确的单元顺序和教学材料时继续扩展这条学习路径，不能将当前按课程展示的小课进度宣称为完整年级教材体系。

### 服务端行为

1. 开始/继续小课时，服务端选择该已发布版本内的可自动评分题目、固定顺序并创建本人学习会话；返回安全题面、逐题状态及下一题。每用户、assessment 和已发布版本只有一个可恢复的学习记录；重复进入沿用该记录，不重置首次作答或累计尝试。答案 key、评分 rubric 不返回。
2. 每次检查答案走既有评分器。服务端保存本轮尝试次数、首次结果、是否曾答错、是否已解出和最新结果；不保存原始答案。请求携带客户端生成的检查 ID，用来防止网络重试重复计次；版本检查处理两个设备同时写入。
3. 每题至少提交一次有效校验才算本轮完成；完成与全对分开，首次答对、重试成功、尚未解决和曾答错可独立呈现。不会用客户端点击“下一题”直接写完成。
4. 会话只允许本人访问；每次重新检查课程公开、未隐藏、assessment 发布且允许自主练习。课程撤回后旧链接、旧会话不能继续读取内容。
5. 课程路径返回本人真实的小课状态与建议继续项；本阶段不设虚假硬解锁。不修改正式考试、成绩、XP、掌握证据或排名。
6. 当前公开自主练习通道仍拒绝受限学员。儿童课堂路径必须实现明确的课程关联与当前成员授权后再开放，不能沿用 public permission 绕开限制。

### 客户端与作者流程

用户明确补充：产品不限老师和学生，普通用户进入也要有课程可以学习，记忆法只是辅助。上一阶段课堂入口已落地，但不能替代这条默认主线。听力媒体审计已完成，广泛音频 schema 编辑暂后置；优先交付现有题型能承载的真实入门课程。

### 交付合同

1. 普通已登录用户不需加入课堂、导入素材或创建记忆集，即可从首页显著入口和一级学习目的地打开平台入门课程。记忆术与原有个人内容保留可达，作为辅助，不抢占默认开始任务。
2. 平台提供原创英语、数学、科学入门课程：讲解、六类活动、服务端评分、解释、总结、错题重练与跨设备继续均真实可用。课程范围诚实标为入门，不宣称官方教材或全学科完整课程。
3. 内容沿用既有 Education 持久实体与发布合同，默认课程有明确系统作者与稳定内容版本；幂等初始化只创建缺失内容，不覆盖用户/教师编辑、已学进度或有意撤回/隐藏的课程。不得用客户端静态卡片或假进度代替课程。
4. 默认课程目录和首页读取服务端真实课程/进度。课程题面、学习材料和已发布版本一致；公开课程也要有讲解，不能只有考试入口或记忆桥接。
5. 普通用户主线与受限学员规则分别处理；不以本次改版暗中开放 RestrictedLearner 的公开浏览权限。受限学员继续走已授权课堂，首页提供其可用的学习入口和说明。
6. 用户验收时必须在 UI 看见真实课程并能开始学习。课程标题、讲解、题面、选项、解释、可见状态与进度均从数据库经 API 动态读取，客户端没有写死课程内容。首批 JSON 仅作新环境初始化数据，不作每次请求的课程替身；后台实际管理员可以管理平台课程，修改不被重启 seed 覆盖。已发布题库按既有不可变合同通过新草稿修订，不改写历史学习记录。

验收：空白新数据库初始化后存在可读、可开始并完成的小课；第二次初始化无重复/不重置；用户无课堂和个人记忆集仍可学；保存/恢复来自服务端；隐藏/撤回与身份切换正确；所有既有记忆功能仍可达。真实数据库、设备与儿童试点的证据需独立记录。

### 已选实施决策

- [三门原创入门课内容规格](starter-course-content.md) 给出讲解与 18 项活动/答案/解释，用于本轮真实 seed；旧私有演示 CSV 不自动升级为公开内容。作品/语音评分与题目音频仍按各自阶段推进。
- 使用现有课程所有者保留值 `system`，不创建虚假的可登录用户；平台作者显示 MemoPal。固定版本 ID，课程存在（包括已删除/撤回/隐藏）即跳过，不在重启时恢复或覆盖。实际管理员通过明确服务端权限管理平台内容，普通教师仍只能管理自己的课程；审核/修改操作者保留真实身份，不冒充 system。后续题库修订创建新草稿，不改已发布题库。
- 新增独立默认开启的 `EducationStarterCatalog:Enabled` 初始化选项，在 schema 初始化后运行，可显式关闭；不因此启用管理员账号或 mock 数据。PostgreSQL 初始化使用事务级锁避免多个实例重复创建，测试明确覆盖重复启动。
- 一级学习入口替换原记忆练习 tab 的主位，旧路由通过可选记忆工具入口保留，不额外增加第七个 tab。首页课程主卡作为普通用户主线；历史记忆入门不再强制阻挡进入课程，记忆集记录仍保留。默认公开课程权限不扩展给受限账号。

### 默认课程与动态管理实际交付

- 新增一级 `learn`，替换原底栏记忆练习的主位；原 `/practice` 路由通过学习页的可选记忆工具入口保留。首页首个内容面板显示服务端课程，学习页以简短介绍、搜索和实际课程卡为主，记忆工具/收藏/历史在次要位置。
- 首页使用单个 `/v1/education/guided/courses/home-progress` 请求选择仍可访问、当前版本、未完成的最近课程；没有未完成课程时返回真实最近进度供复习。客户端有服务端结果时始终采用它，不把其他未知课程推断为未学；没有学习记录才展示目录入门课。支持继续不在目录当前 100 项中的课程，避免每门课程一个进度请求。

- 实际管理员通过现有 Education 作者页面管理 `system` 平台课程；普通教师仍只管理本人课程。新增课程标题修改，学习条目沿用撤回→编辑→发布，已发布题库保持不可变，后续修改通过创建新草稿 assessment。权限标志由控制器从认证角色设置，客户端请求中的 `isAdmin` 不授予能力；不冒充 system 操作者。

## 15. 动态小课修订与自主学习可见性（进行中）

普通用户课程不能只在首次初始化时有内容，还需要可维护的作者流程。当前已发布题库只读，后台虽可创建新空白 assessment，但修订一节已有小课需要手动重建。本阶段补齐明确操作，继续复用同一数据库与作者合同。

- 已发布小课可由课程所有者或平台课程的真实管理员创建修订草稿；复制题目、选项、答案与解释到新 assessment，题目 ID 全新，仍通过既有 authoring 校验。草稿不进入普通用户课程，发布仍走现有明确自主练习选项。
- 原小课的题面、版本、学习会话、正式作业与成绩均保留。不自动隐藏旧课；作者在新版发布后可独立停止旧课的自主学习展示。
- 使用现有 `IsPublicPractice` 单独控制已发布小课是否允许自主学习，不把可见性变更当作内容版本升级。开启需明确确认适合自主练习；关闭后旧 guided GET/check/幂等重放均重新鉴权拒绝，重新开启可恢复原记录。正式考试/成绩读取和提交不依赖此开关。
- 管理端呈现创建修订草稿、开关、加载/错误/重试及说明，避免重复点击创建多个草稿；权限从认证身份获得，不能由请求体伪造。
- 同时修复公开课程详情 focus 手动 refetch 对受限身份的禁用检查，避免页面已跳转仍请求公开 API。

需要端点测试证明新旧内容与进度隔离、作者权限、草稿不可见、隐藏/重新开启行为及正式记录不变；管理端需要真实 UI 行为测试。用户要求的完整已登录客户端 UI 验收仍待运行地址，不能以本阶段测试代替。
