## 统一标准

- 紫色用于主要动作；学科色用于柔和浅底及分类。深色模式保留清楚的文字与选中状态。
- 正文以 15/23、辅助文字以 14/21 为基准；局部标签至少 13px，允许系统文字缩放。
- 每个界面有明确主动作。卡片内的普通入口优先用列表行，避免多重边框。
- 功能图标采用 Ionicons；教学图形保持足够大，配文字说明，不只靠颜色传达状态。
- 首次练习提示紧凑可关闭；反馈与正文可滚动，操作区域不遮挡内容。
